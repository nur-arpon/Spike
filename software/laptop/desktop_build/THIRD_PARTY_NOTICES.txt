Third-party software in the built-in brain (the "brain" folder of the Windows app)
===================================================================================

The brain is built from open-source components. Each keeps its own licence; the
full licence texts are in the matching *.dist-info folders inside "_internal".

Models
- Whisper base.en (OpenAI, converted to CTranslate2 by SYSTRAN) ... MIT
- vosk-model-small-en-us-0.15 (Alpha Cephei) ....................... Apache-2.0
- Silero VAD (silero_vad.onnx, Silero Team) ........................ MIT

Nothing here sends data anywhere on its own. Speech recognition, wake words and
voice-activity detection run on this computer; the conversation text and the voice
requests go to Google's Gemini API only with the key the user pasted.
